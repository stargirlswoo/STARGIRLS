# Checkout launch checklist

- Finalize real product names, prices, sizes and SKUs.
- Confirm which SKUs are Apliiq vs STARGIRLS-stocked inventory.
- Deploy Worker.
- Add Stripe secret in Worker secrets.
- Set `store-config.js` to the Worker URL.
- Test cart on mobile and desktop.
- Test one real order end-to-end.
- Confirm payment success page.
- Confirm fulfillment routing and tracking.
- Only then switch launch products to `available: true`.
